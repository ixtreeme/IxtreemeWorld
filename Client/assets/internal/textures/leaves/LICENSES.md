# Stylized Leaf Atlases

The `*_leaf.png` files in this folder are procedurally generated project assets.

- Source: generated locally for IxtreemeWorld / ixtreemetree.
- Third-party input: none.
- License status: no external copyrighted texture source was used.
- Format: 512x512 RGBA PNG, 2x2 atlas grid, four stylized leaf silhouettes per texture.
